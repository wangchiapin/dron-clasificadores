# 題庫說明

遊戲從這三個 CSV 檔讀題目，用 Excel 或 Google 試算表就能編輯（存檔格式選「CSV UTF-8」）。第一列是標題，不要刪。

## classifiers.csv（量詞射擊）
| 欄位 | 說明 |
|---|---|
| 分類 | 動物、物品…（選單的分組） |
| 分類西文 | 分組的西班牙文名稱 |
| 名詞 | 題目的名詞，例如「貓」 |
| 拼音 | 名詞的拼音 |
| 西文 | 名詞的西班牙文（不要寫出量詞，會洩漏答案） |
| 正確量詞 | 正確答案；有多個都算對就用 `/` 分開，例如 `支/枝` |
| 不可當干擾項 | 這題的錯誤選項「不能」出現的量詞（其實也說得通的），用 `/` 分開，沒有就留空 |

## measure-words.csv（量詞表）
| 欄位 | 說明 |
|---|---|
| 量詞 | 量詞本身 |
| 拼音 | 拼音（開「顯示拼音」時用） |
| 可當干擾項 | 填 `是`：可以當別題的錯誤選項；填 `否`：只會當正確答案出現（例如「個」） |

新增題目時，如果用到新的量詞，要先在這個檔案加一列。

## words.csv（飛過門）
欄位：主題、主題西文、詞、拼音、西文。每個主題至少 3 個詞。

資料有問題的列會被略過，選單下方會顯示提醒。
